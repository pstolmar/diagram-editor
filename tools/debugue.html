What is happening: The component tree loads fine. Only clicking a component to edit it fails. This means the page instrumentation is correct — the problem is the UE service → AEM Author roundtrip that happens when you select a component.

The UE service proxies to AEM Author. The UUID in the error is the UE service trace ID for that request.

Common causes of ISE on CF edit:
1. CF path referenced in data-aue-resource doesn't exist on AEM Author (was deleted, renamed, or never created)
2. AEM Author service account doesn't have read permission on that CF
3. The model ID in data-aue-model exists in component-models.json but has no matching AEM model node — check /conf/global/settings/dam/cfm/models/
4. UE service version mismatch with your AEM Author version (check UE release notes)
5. Most likely if it recently broke without code changes: an AEM Author maintenance operation (index rebuild, migration, restart) left a lock or inconsistency on that specific CF node
