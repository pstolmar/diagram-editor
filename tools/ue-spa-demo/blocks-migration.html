edit_note Section 3 — Adding Universal Editor to an EDS Block

The same teaser block becomes editable in Universal Editor by adding data-aue-* attributes to the HTML that AEM delivers. No changes to the block JS or CSS.

integration_instructions UE Instrumentation — Teaser Block data-aue-* attributes bridge authoring to editing

layers

Three concerns, composing cleanly. EDS blocks are the only component type where the authoring model (Word table), the delivery model (semantic HTML rendered by the decorator), and the editing model (data-aue-* attributes for Universal Editor) are all separate concerns. Change the authoring structure without touching the JS. Change the decorator without modifying the content model. Add UE instrumentation without altering either. No coupling in either direction.

trending_flat Section 4 — Migration guide (4 steps)
1
Export content
arrow_forward Extracts from JCR

Use the AEM content migration script — or simply copy-paste — to extract content from Core Component JCR properties into Word documents, Google Sheets, or Document Authoring pages. One table row = one authored field.

aem export --component teaser --output /sharepoint/content
2
Create the block folder
arrow_forward Replaces HTL + Sling model

Add blocks/teaser/teaser.js and blocks/teaser/teaser.css. The decorate(block) function reads the Word-authored table structure — first column image, second column content cells. No AEM, no Java.

blocks/teaser/ teaser.js ← decorator teaser.css ← styles
3
Add UE instrumentation
arrow_forward Replaces cq:editConfig + dialog

Add data-aue-resource, data-aue-type, and data-aue-prop attributes — either directly in the block JS (for JS-controlled rendering) or via component-models.json for the page-level editing model.

data-aue-resource="urn:aem:…" data-aue-type="component" data-aue-prop="title"
4
Sunset the Core Component
arrow_forward Remove Java + XML dependency

Once content is migrated and the block is verified in both rendering and UE editing, remove the Core Component OSGi dependency. Delete the HTL template, Sling model, and dialog XML. No more Java build step, no more XML config, no more AEM coupling.

git rm -r src/main/java/…/Teaser* git rm -r ui.apps/teaser/_cq_dialog
