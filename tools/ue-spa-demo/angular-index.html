Key constraint: The SPA never calls Author directly. UE editing goes through universal-editor-service.adobe.io which proxies to Author. Your Angular app only ever speaks to the Publish tier — keeping your public CDN deployment completely isolated from authoring credentials.

AEM Hybrid architecture

language
This app is on EDS — but it doesn't have to be.

This Angular app is hosted on EDS (aem.live) for this demo — but the pattern is entirely host-agnostic. Any publicly-accessible Angular URL can be loaded in Universal Editor for WYSIWYG editing. Your existing Angular deployment on your own CDN, AWS, Azure, or any cloud works exactly the same. The only requirements are a reachable URL, the cors.js script tag, and the AEM UE meta tag pointing to your Author instance.

Quick deploy

If UE stops working

terminal Shell · CORS config redeploy

Universal Editor relies on two CORS config packages deployed to the AEM RDE Author tier. If UE shows a blank Properties panel or stops saving, redeploy them:

# If UE stops working, redeploy CORS configs:
aio aem:rde:install tools/cors/ui.config-ue-cors-1.0.zip --target author
aio aem:rde:install tools/cors/ui.config-ue-bearer-1.0.zip --target author
