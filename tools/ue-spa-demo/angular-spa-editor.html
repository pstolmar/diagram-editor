trending_flatSection 4 — Migration guide
1
Create Content Fragment Models
arrow_forward Replaces AEM Component dialogs

In the AEM UI, define a Content Fragment Model for each component type — fields, types, validations. This replaces all _cq_dialog.xml and Sling model field definitions. Authors create CF instances directly from these models.

2
Replace MapTo() with data-aue-* attributes
arrow_forward Replaces all SPA Editor component registrations

In your Angular templates, remove all MapTo() calls and EditableComponent wrappers. Add data-aue-resource, data-aue-type, and data-aue-prop directly to your existing HTML elements. No AEM dependency imported.

3
Update data fetching to GraphQL Publish
arrow_forward Replaces ModelManager / AemPageModel calls

Remove all ModelManager.initialize() and AemPageModel imports. Replace with a simple fetch() to your GraphQL persistent query endpoint on Publish — CDN-cached, fast, no Author dependency. Add a message listener for aue:content-patch to refresh after UE edits.
