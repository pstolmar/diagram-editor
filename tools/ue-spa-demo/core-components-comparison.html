What Changed
⚡
No Server Render
HTML delivered from CDN edge, not from AEM Publish server. Zero Sling request pipeline on the delivery path.
📝
Same Author Experience
Authors still use AEM — Universal Editor for WYSIWYG, or Word/DA for document-based authoring. No retraining needed.
🔧
One JS File Per Block
decorate() replaces HTL templates, Sling models, and OSGi dialog XML. The whole block fits in a single ~50-line file.
🔗
CF Data via GraphQL
Content Fragments fetched headlessly from the Publish tier. Fully UE-editable at the CF level — no page publish required.
