Edge Delivery Services 2.0 is here

Today we are announcing the next generation of Adobe Edge Delivery Services — a delivery platform that serves enterprise web experiences from 300 global edge nodes with consistent 100 ms Time to First Byte, perfect Core Web Vitals, and zero infrastructure for your team to manage.

Request an early access demo Read the documentation

What's new in 2.0

Instant authoring with DA Live

Author directly in DA Live's browser editor or in Microsoft Word and Google Docs. Changes publish to the live site in under five seconds — no export, no sync job, no waiting.

Explore DA Live authoring

WYSIWYG with Universal Editor

Non-technical authors get full in-context editing powered by the Universal Editor. Click any block on the live page and edit it inline — no CMS training required.

See the Universal Editor

Perfect Core Web Vitals by default

Every EDS page ships with lazy-loaded images, critical CSS inlined, and zero render-blocking scripts. A 100 Lighthouse score is the floor, not a goal to optimise toward.

View performance benchmarks

Migrate in weeks, not quarters

The blockify toolset converts your existing AEM Core Components HTML into EDS block HTML in a single paste operation. Each section is classified, mapped to the closest EDS block, and output as a working scaffold you can edit and ship immediately.

Most teams complete a full site migration in four to six weeks, including performance testing and content author training.

  • Automated AEM component analysis
  • Block scaffold generation with confidence scoring
  • Sandbox previews before committing to the repo

A development model that gets out of your way

Every EDS block is a plain JavaScript module that receives a DOM element and transforms it. No framework. No virtual DOM. No build pipeline required.

Blocks auto-load their CSS sibling only when the block appears on the page, so no unused code is ever shipped to users.

  • Start with aem up — no Docker, no Maven
  • Hot reload from GitHub on every save
  • Deploy by merging a pull request
