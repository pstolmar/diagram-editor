Edge Compute Layer

AEM Edge Function injects live data into a static page

The EDS page never changes — but the edge worker calls the reservations API on every request and injects current availability directly into the HTML stream before it reaches the browser.

edge-fn/table-availability.js
// Intercept every request to the Saffron page export default { async fetch(req, ctx) { const res = await ctx.next(req); // static EDS HTML const { tables, next_slot } = await fetch('https://api.saffron.co.uk/reservations/tonight') .then(r => r.json()); return new HTMLRewriter() .on('body', { element: el => el.prepend(badge(tables, next_slot), { html: true }) }) .transform(res); } }
