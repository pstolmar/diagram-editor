Section 04
CJA Audiences + EDS Experimentation
RUM data feeds Customer Journey Analytics. CJA-defined audiences are applied at the edge as personalization segments. EDS native Experimentation runs A/B tests on the same page — no separate platform.
👥 CJA Audience Segments Powered by RUM + CJA
RUM is built into EDS aem.js — sampled events flow to CJA, which segments visitors and returns audience IDs as edge cookies. No separate CDP tag required.
